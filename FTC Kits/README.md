# FTC Kits

This folder has everything for the upgrade kits from Prolabs Robotics, one folder per kit. Each kit folder has the assembly guide, the parts list, and a short README.

| Kit | What it does | Start here |
|---|---|---|
| [Shooter Upgrade Kit](./Shooter%20Upgrade%20Kit) | V3 precise shooter for the goBILDA FTC StarterBot 2026-27 | [V3 Shooting Assembly Guide](./Shooter%20Upgrade%20Kit/V3%20Shooting%20Assembly%20Guide.pdf) |
| [Intake Upgrade Kit](./Intake%20Upgrade%20Kit) | FTC intake attachment with a foam wrap that grips the POLLEN | [Intake Assembly Guide](./Intake%20Upgrade%20Kit/Intake%20Assembly%20Guide.pdf) |

The 3D print source files stay in their own folders:

- V3 shooter: [FTC precise shooting mechanism/V3 Shooter 3D files](../FTC%20precise%20shooting%20mechanism/V3%20Shooter%203D%20files)
- Intake: [FTC Intake mechanism Upgrade](../FTC%20Intake%20mechanism%20Upgrade)

Print every kit part at 100% infill.
