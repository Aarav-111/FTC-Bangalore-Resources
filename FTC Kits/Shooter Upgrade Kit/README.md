# Shooter Upgrade Kit (V3)

The V3 shooter upgrade for the goBILDA FTC StarterBot 2026-27, by Aarav J. (Prolabs Robotics), with R-Factor FRC.

## What is in the kit

| Part | Qty | Notes |
|---|---|---|
| V3 main shooter (rail guard) | 1 | 3D print, 100% infill |
| Plate 368 (5 x 5 holes) | 2 | 1 used, 1 spare |
| Prolabs OP2 sheet | 2 | Both used, one on each side, flared out about 15 degrees like a funnel |
| Electrical tape | 1 roll | Goes over the zip ties, never straight onto V3 |
| Zip ties | 1 bag | 16 per robot |
| Super glue | 1 small bottle | A few drops on the front edge of each sheet |

V2 is an older version and is not in the kit.
