# V2 Shooter 3D files: what to print

Print these 3 files, 1 of each, all at **100% infill**.

| # | File | Part | Size |
|---|---|---|---|
| 1 | `FTC Shooter V2 Rail Guard.stl` | V2 rail guard (print sideways) | about 129 x 149 x 88mm |
| 2 | `prolabs_plain_sheet_0p2.stl` | Prolabs Flex Sheet (flat on bed) | 88 x 104 x 0.2mm |
| 3 | `plate_368_cut_5x5.stl` | Plate 368 replacement (flat on bed) | 40 x 40 x 1.5mm |

Instead of printing plate 368, you can cut 56mm (7 hole rows) off the kit plate 368.

Full steps: [BOM & 3D printing Guide](../BOM%20%26%203D%20printing%20Guide.md) and [Build guide PDF](../V2_flexplate_build_guide.pdf).
